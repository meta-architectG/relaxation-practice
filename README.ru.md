# Практики саморегуляции (Relaxation Practice)

PWA для дыхательных практик, заземления и снятия стресса. Сделано на React 19 + Vite.

## Ссылка на сайт

[Посмотреть вживую](https://relaxation-practice.meta-architect.workers.dev)

## Стек

- **React 19** (хуки, порталы)
- **Vite** (сборка)
- **Vanilla CSS** (переменные, grid/flex, адаптив)
- **Vitest + React Testing Library** (тесты)
- **vite-plugin-pwa** (установка на экран, офлайн)

## Фичи

- **Дыхание**: таймер с шагом 50мс, синхронизирован с SVG-кольцом. Использует `Wake Lock API`, чтобы экран не гас.
- **Заземление**: поиск 5 предметов по случайному цвету, сброс прогресса при смене цвета.
- **Релаксация**: таймеры на напряжение (5с) и расслабление (15с), автоматическое переключение фаз.
- **Мысли**: textarea с анимацией растворения текста.
- **PWA**: ставится на iOS/Android, обновляется само.

## Код и архитектура

- Вся логика вынесена в кастомные хуки (`useBreathingTimer`, `useLockBodyScroll`), компоненты только рендерят UI.
- В модалках есть фокус-трап, закрытие по `Escape` и клику по фону.
- Учтены системные настройки `prefers-reduced-motion` (для тех, кого укачивает от анимаций).
- Написано 11 тестов (проверяют хуки, навигацию и формы).
