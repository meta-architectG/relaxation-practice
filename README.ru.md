# Практики саморегуляции (Relaxation Practice)

Веб-приложение (PWA) для дыхательных практик, снятия стресса и заземления. Проект создан с фокусом на чистую архитектуру, доступность (A11y), производительность и плавные микро-анимации.

## Живая демонстрация

[Посмотреть работающее приложение](https://relaxation-practice.layero.app)

## Стек технологий

- **Core:** React 19 (Hooks, Portals)
- **Сборка:** Vite
- **Стилизация:** Vanilla CSS (CSS-переменные, Grid/Flexbox, полная адаптивность)
- **Тестирование:** Vitest, React Testing Library, JSDOM
- **PWA:** `vite-plugin-pwa` (установка на домашний экран, автообновление)
- **Аналитика:** Top.Mail.Ru (VK)

## Реализованный функционал

- **Дыхательная практика:** Кастомный таймер с высокой точностью (тик 50мс), синхронизация с SVG-прогресс-баром и использование `Wake Lock API` для предотвращения затухания экрана.
- **Заземление:** Интерактивный интерфейс со случайной генерацией цветов, логикой подсчета 5 предметов и сбросом прогресса.
- **Мышечная релаксация:** Пошаговое руководство с автоматическими таймерами для фаз напряжения (5 сек) и расслабления (15 сек).
- **Отпустить мысль:** Форма ввода с анимацией растворения, симулирующей избавление от негативных мыслей.
- **PWA:** Полностью устанавливается на главный экран iOS/Android с автообновлением через Service Worker.
- **Адаптивность:** Корректное отображение на всех устройствах от мобильных экранов (320px) до 4K-мониторов.

## Архитектурные решения

- **Разделение логики и UI:** Вся бизнес-логика вынесена в кастомные хуки (`useBreathingTimer`, `useLockBodyScroll`), что делает UI-компоненты чистыми и сфокусированными на отрисовке.
- **A11y (Доступность):**
  - Полноценный Focus Trap в модальных окнах и поддержка клавиши `Escape`.
  - Поддержка `prefers-reduced-motion` для отключения анимаций у пользователей с вестибулярными нарушениями.
  - Семантическая верстка и корректные атрибуты `aria-label`.
- **Тестирование:** Написано 11 тестов, покрывающих критические сценарии (юнит-тесты для хуков, интеграционные тесты для навигации, UI-тесты для модалок и форм).

## Как запустить локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/meta-architectG/relaxation-practice.git

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```
