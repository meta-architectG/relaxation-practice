# Практики саморегуляции (Relaxation Practice)

Веб-приложение (PWA) для дыхательных практик, снятия стресса и заземления. Написано на React и Vite с фокусом на чистую архитектуру, доступность (A11y) и плавные микро-анимации.

## Живая демонстрация

[Посмотреть работающее приложение](https://relaxation-practice.layero.app)

## Стек технологий

- **Core:** React 19 (Hooks, Portals)
- **Сборка:** Vite
- **Стилизация:** Vanilla CSS (CSS-переменные, Grid/Flexbox, адаптивная верстка)
- **Тестирование:** Vitest, React Testing Library, JSDOM
- **PWA:** `vite-plugin-pwa` (установка на экран, автообновление)
- **Аналитика:** Top.Mail.Ru (VK)

## Функционал

- **Дыхательная практика**: Кастомный таймер с точностью до 50мс, синхронизированный с SVG-прогресс-баром. Использует Wake Lock API, чтобы экран не гас.
- **Заземление**: Интерактивный интерфейс со случайной генерацией цветов, подсчетом 5 предметов и сбросом прогресса.
- **Мышечная релаксация**: Пошаговое руководство с автоматическими таймерами для фаз напряжения (5 сек) и расслабления (15 сек).
- **Отпустить мысль**: Форма ввода с анимацией растворения, симулирующей избавление от негативных мыслей.
- **PWA**: Полностью устанавливается на iOS/Android с автообновлением через Service Worker.
- **Адаптивность**: Корректно отображается от мобильных экранов (320px) до 4K-мониторов.

## Архитектура и качество кода

- **Разделение логики и UI**: Вся бизнес-логика вынесена в кастомные хуки (`useBreathingTimer`, `useLockBodyScroll`). UI-компоненты остаются чистыми и отвечают только за отрисовку.
- **Доступность (A11y)**:
  - В модальных окнах реализован Focus Trap и закрытие по клавише `Escape`.
  - Поддержка `prefers-reduced-motion` для отключения анимаций у пользователей с вестибулярными нарушениями.
  - Семантическая верстка и атрибуты `aria-label`.
- **Тестирование**: Написано 11 тестов (юнит-тесты для хуков, интеграционные для навигации, UI-тесты для модалок и форм).
